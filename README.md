# Myne Bot

Automation account for [Myne](https://myne.md). This is not a person.

It triages issues and reviews pull requests inside the [`myne-md`](https://github.com/myne-md)
organization. It never assigns anyone, and it never names a label, milestone or repository
that the request did not already carry.

The project lives at **[github.com/myne-md](https://github.com/myne-md)**.
